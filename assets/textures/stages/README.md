# Stage SVG Textures

Stage-specific SVG albedo textures for the current continuous-stage content.

- `piata/`: Piata Basement chunk surfaces
- `academy/`: Academy B1/B2/B3 room surfaces
- `birth_valley/`: Birth Valley path, cave, boss, and foundation surfaces

These are vector-first albedo textures intended to replace placeholder or reused
generic bitmap surfaces while keeping the existing scene materials lightweight.
